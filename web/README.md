# SPECTRA EQ 2.5.0-system

A normal system equalizer: the knobs change every sound you play.

Windows will not let an app EQ the speakers by listening to them (that feeds back).
The programs that "just work" install a small audio effect. Spectra drives that effect.
No virtual cable.

## First time

1. Rebuild so the title says `2.5.0-system`
2. Press EQ ON → Install system EQ
3. Install Equalizer APO, tick your Speakers, reboot
4. Open Spectra, press EQ ON, turn the knobs

EQ OFF puts the sound back to flat. The mesh is only the live view.
